# 实战学习空间

这是根据《Java Python 爬虫实战学习平台需求分析》v0.4 落地的电脑端静态原型，聚焦“先学再练、再做项目、再做独立变更”的学习闭环：

- 首页明确当天下一步，并支持 15 / 30 / 60 分钟计划；
- Java 后端、Python 自动化、Python 爬虫三条可切换学习路线；
- 每个单元明确“知识与示例 → 引导练习 → 独立练习”的顺序；
- 面向大四软件工程学生的 Java 后端求职目标、岗位能力雷达和企业开发能力清单；
- Java、Python、爬虫三套阶段测验，提交后给出错题原因和复习建议；
- 三条路线共 1215 题原创场景变式题库（每条路线 405 题），每次随机抽取 8 题，保存最近得分和错题复习方向；
- 任务详情、示例代码、分层提示、完成条件与自检记录；
- 问题整理：现象、预期、尝试动作、下一小步；
- AI 答疑上下文整理，区分站内 AI 未配置与外部网页辅助；
- Java、Python、爬虫共 8 个项目方向与多项独立需求变更；
- 成果档案与浏览器本地 JSON 导出；
- 外部课程登记与版本边界说明。

## 运行

直接双击 `index.html` 即可打开。也可以在当前目录启动任意静态文件服务器，例如：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 范围说明

当前版本是前端可操作原型，题库通过原创题干、场景和知识点组合生成 1215 题，仍需在真实学习过程中持续复核题目质量。课程数量和项目库属于内容规划与交互展示，仍需逐项补齐课程正文、数据包、参考实现和运行验证。学习记录使用浏览器 `localStorage` 保存；没有真实账号、服务端数据库、站内模型 API、在线执行用户代码或 Java/Python 项目源码仓库。页面对这些边界做了明确提示，避免把自检当成平台评测、把导出快照当成代码备份。
