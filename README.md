# 实战学习空间

这是根据《Java Python 爬虫实战学习平台需求分析》v0.4 落地的首版电脑端静态原型，聚焦 P0 学习闭环：

- 首页明确当天下一步，并支持 15 / 30 / 60 分钟计划；
- Java 主线路线与阶段进度；
- 任务详情、示例代码、分层提示、完成条件与自检记录；
- 问题整理：现象、预期、尝试动作、下一小步；
- AI 答疑上下文整理，区分站内 AI 未配置与外部网页辅助；
- 设备台账工具、设备借用管理后端两个项目的里程碑；
- 成果档案与浏览器本地 JSON 导出；
- 外部课程登记与版本边界说明。

## 运行

直接双击 `index.html` 即可打开。也可以在当前目录启动任意静态文件服务器，例如：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 范围说明

当前版本是前端可操作原型，记录使用浏览器 `localStorage` 保存；没有真实账号、服务端数据库、站内模型 API、在线执行用户代码或 Java 项目源码仓库。页面对这些边界做了明确提示，避免把自检当成平台评测、把导出快照当成代码备份。
