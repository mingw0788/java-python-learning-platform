# 向实战 DevPath

面向大四软件工程学生的个人学习工作台：按任务学习 Java、Python 和爬虫，积累可解释、可运行、可交付的作品。

## 本次重建

- 重新设计首页、导航、路线、课程、项目、测验、错题、求职、笔记与资料页面；支持电脑与手机。
- 首页提供下一节建议、15 / 30 / 60 分钟计划、真实保存记录统计；优先方向和每周时间可调整。
- 28 节主题课：Java 10、Python 8、爬虫 6、工程与求职 4。每节均含自有讲解、代码片段与运行上下文、操作步骤、独立变式、三项验收、自测与实践记录。
- 所有课程都可进入；先修关系为建议，不用虚假的解锁按钮阻塞学习。路线顺序根据实际保存的独立自检推进。
- 12 份项目任务书，覆盖台账、借用、工单、预约、清洗、周报、归档、API 巡检、静态采集、动态页面、增量数据与接手项目。共 48 个里程碑，可记录进度并导出任务书和项目现场。
- 3 个可下载练习包，含 Java / Python 参考实现、样例输入、预期输出和检查说明；源码在 materials/。
- 1,243 条题目记录：旧题库 1,215 条（含 1,170 条由 39 类知识模板变换场景得到的变式），新增 28 道课程自测。不是 1,243 个独立知识点。修正了旧模板中事务、数据库约束和重试等 210 道题的场景语义，以及 30 道数据校验选项的脱敏表述。
- 题库支持方向 / 主题 / 类型筛选，5 / 10 / 20 / 30 题组卷、优先未答题、随机选项、断点恢复、未答校验、计分解析和错题重练。筛选池不足时按实际可用数量组卷。
- 20 个面试追问，支持自己的回答与参考组织思路分开；项目表达可导出 Markdown，不编造用户量或性能数据。
- 课程与项目全文搜索、收藏、问题上下文提问、笔记编辑删除、JSON 备份恢复。

## 本地运行

发布产物已包含在 dist/，无需安装前端依赖：

```powershell
python -m http.server 8000 --bind 127.0.0.1 --directory dist
```

访问 http://127.0.0.1:8000 。建议始终使用同一地址与端口，浏览器记录按来源隔离。

修改源文件后，使用 Node.js 与 Python 构建静态文件和练习包：

```powershell
node build.mjs
```

入口文件 index.html；样式 styles.css；课程 / 项目 content.js；旧题库 questions.js；交互 app.js。dist/ 是构建产物，不应单独修改。

## 学习包

- Java 台账：materials/java-ledger，使用 JDK 21 编译运行，样例有效 3 条、错误 2 条。
- Python 清洗：materials/python-cleaner，标准库实现；样例有效 2 条、错误 4 条，附 unittest。
- 本地采集：materials/local-crawler，标准库实现；本地三页产生 3 条唯一记录，附解析测试和失败场景说明。

网站的 SQL / Spring / HTTPX / Playwright 示例会标明环境或前提；它们是教学片段，完整业务服务需要按项目任务书实现。

## 数据与边界

学习数据保存在 localStorage 的 devpath-workspace-v2 中。阅读、答题、带帮助实践和独立实践自检分别记录；平台不执行用户代码，不提供可信在线评测，不承诺就业结果。

从旧 learning-space-state-v1 自动迁移问题笔记并保留完整旧快照，不删除旧键。旧版的预设进度不冒充新课程的实际完成。新课学习记录支持 JSON 导出与校验恢复；恢复前会下载当前记录备份。

没有新增付费服务、模型 API 或云端学习数据库。AI 辅助提供基于课程的提问文本与外部入口。换浏览器或设备前请导出；源代码和数据库需另行备份。
