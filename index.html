第 01 单元 · 环境与开发基本操作

输入、运行与解释结果

完成一次最小闭环：知道在哪里输入命令，修改一个输入，再次运行，并用自己的话说出结果为什么变化。

这次要解决什么？

你将让程序读取一个名字并输出问候。改动输入后，输出应该随之变化。这个任务看似很小，但它会训练之后每个接口都要用到的基本习惯：输入是什么、程序做了什么、结果如何验证。

输入

一个姓名，例如 Lin

产出

一行可解释的输出

约束

改动后要再次运行

先看一个可运行示例

// Hello.java
public class Hello {
  public static void main(String[] args) {
    String name = "Lin";
    System.out.println("你好，" + name + "！");
  }
}

预期输出：你好，Lin！。把 Lin 改成你自己的名字，再运行一次。

完成条件

不要一次看完答案

提示 1 · 先确认你要观察的变化

只改一个东西：字符串 "Lin"。如果同时改了文件名、类名和命令，就不容易知道是哪一步造成结果变化。

提示 2 · 检查运行位置

在终端输入命令前，先确认当前目录里能看到 Hello.java。路径含空格时不要凭感觉拼接，先用文件管理器复制路径或在终端检查。
