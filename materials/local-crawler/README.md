# 本地课程目录采集

只请求本机练习服务，不需要任何外部网站或第三方库。Python 3.9+ 可运行。

终端 1，在本目录启动练习源（保持运行）：

```powershell
python -m http.server 8000 --bind 127.0.0.1 --directory pages
```

终端 2，在同目录执行：

```powershell
python collect.py --base http://127.0.0.1:8000 --output result.json
python -m unittest -v
```

预期：唯一记录=3 完整=True；成功访问页号 [1,2,3]。第二页有一个重复 p1，第三页为空页。

再次运行结果仍只有 3 条，不重复追加。关闭终端 1 的服务器后再次执行应生成错误清单并返回非零退出码。

本示例按页码最多请求 3 页，使用 HTMLParser 处理给定练习结构。它不提供通用浏览器渲染或通用爬虫框架。失败处理为保留错误并停止，下一步独立练习实现有限重试与补采队列。

独立练习：删除其中一条标题后仍保留其他有效记录；补充新增、更新与跳过计数；在 SQLite 中持久化。提交代码、来源字段、质量报告与 README。
