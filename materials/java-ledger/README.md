# 设备台账基础参考

环境：JDK 21；不需要额外依赖。本包是学习参考，先按网站任务书尝试，再看实现。

在本目录终端执行：

```powershell
javac -encoding UTF-8 Ledger.java
java Ledger devices.tsv
```

预期：有效=3 错误=2。有效编号 A01、A02、A03；重复 A01 和空编号在错误输出中显示。

输入使用 TSV，表头为 id 与 name，按 TAB 分隔；不支持字段内换行或 TAB。不要把这个简单分隔器当成完整 CSV 解析器。

独立练习：增加查询参数、状态字段、停用筛选，并将错误输出到文件。准备空文件、错误表头、重复编号、空名称四种回归样例。

提交物：修改后的源代码、运行记录、边界结果、README 与独立需求变更说明。
